The "Grocery List" (Basic Methods)
==================================

👉 **Goal:** Practice the array methods: `.push()`, `.find()`, `.filter()`, and `.forEach()`.

👉 **Instructions:** 

Create three functions:

*   `checkGuestList`: it adds a new item at the end of an array if the item is not already in the list. If the item is already in the list, log an appropiate error message in the console. It needs to pass two parameters:
    
    1.  `array`: is the array where the item needs to be pushed into.
        
    2.  `item`: is the item that needs to be pushed into the array. 
        
*   `deleteItem`: it deletes an item from the array by using its value. It needs to pass two parameters
    
    1.  `array`: is the array from where the item needs to be deleted.
        
    2.  `item`: is the item that needs to be deleted.
        
*   `printItems`: logs into the console each one of the items in the array. It needs to pass one parameter:
    
    1.  `array`: the array that will be looped through.

Test if your functions work by: 

*   Adding to the shopping list array the items: `Eggs`, `Milk`, `Bread`, `Mandarines`, `Bananas` and `Eggs`.
    
*   Removing the item `Milk` from the shopping list.
*   Display the final list in the console.
